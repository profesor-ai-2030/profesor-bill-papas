## Enfoque elegido: Laboratorio editorial

### Design Movement
Editorialismo científico contemporáneo, con referencias a publicaciones de arquitectura, cuadernos de laboratorio y visualización de datos de precisión.

### Core Principles
1. El contenido profesional debe sentirse verificable y ordenado, no promocional.
2. La asimetría crea una lectura de investigación: cada bloque parece una página de un dossier.
3. La tecnología aparece mediante diagramas, índices, orbitales y líneas de datos, no mediante clichés de neón.
4. La calidez humana equilibra el lenguaje técnico para que el visitante entienda el valor práctico de cada servicio.

### Color Philosophy
El marfil funciona como papel de archivo y permite que el contenido respire. El azul petróleo comunica profundidad, criterio y confianza. El cobre se reserva para fechas, nodos y acciones importantes: es la señal de descubrimiento dentro de un sistema sobrio.

### Layout Paradigm
Una portada editorial de doble ritmo: navegación estrecha, hero dividido entre manifiesto y visual científico, después una secuencia vertical de secciones con bandas laterales, números de índice y una línea temporal que cruza el contenido. Se evita el centrado uniforme y se emplean offsets controlados.

### Signature Elements
- Índices numerados en cobre con líneas finas de conexión.
- Orbitales y retículas de puntos como textura de fondo.
- Tarjetas de servicio con etiquetas de disciplina y un borde lateral de color.

### Interaction Philosophy
Las interacciones deben sentirse como consultar un archivo: rápidas, precisas y con feedback discreto. Los botones se elevan apenas, los enlaces revelan una línea cobre y los elementos de la trayectoria se expanden sin saltos bruscos.

### Animation
Entradas suaves con desplazamiento vertical corto y opacidad, escalonadas por bloques. Los nodos de la línea temporal pueden pulsar con lentitud, pero nunca deben distraer. Toda animación no esencial queda desactivada bajo `prefers-reduced-motion`.

### Typography System
Comfortaa es la tipografía principal solicitada y se utiliza en toda la interfaz con pesos diferenciados. Los títulos usan 700 y tracking negativo; el cuerpo usa 400; las etiquetas técnicas usan 600, mayúsculas y tracking amplio. La jerarquía depende más del tamaño, el peso y el espacio que del color.

### Brand Essence
Un profesor-consultor que convierte datos, inteligencia artificial y pensamiento sistémico en decisiones útiles para organizaciones y equipos. Personalidad: **riguroso, curioso, generoso**.

### Brand Voice
Los titulares son directos y reflexivos. Las llamadas a la acción invitan a conversar sobre un problema concreto, no a comprar una promesa. Microcopy: claro, humano y con vocabulario técnico solo cuando aporta precisión.

Ejemplo 1: “De la complejidad técnica a una dirección que se puede ejecutar.”

Ejemplo 2: “Trae una pregunta difícil. La convertimos en un mapa de trabajo.”

### Wordmark & Logo
El símbolo combina un nodo neuronal, una órbita y una pista de circuito en una figura geométrica compacta. El nombre se compone en Comfortaa Bold con un pequeño separador cobre, evitando un logotipo genérico.

### Signature Brand Color
Cobre de laboratorio `#C9794B`, usado como señal de hallazgo, no como relleno dominante.
